# 早起き

早起きと、日課・TODOをゲーム感覚で続けるための自分専用の画面です。GitHub Pages で公開しています。

- 曜日ごとの目標の時間までに「起きた！」、15分後に「まだ起きてる！」を押すと大成功。ひよこが育ち、🔥連続記録が伸びます（7日ごとにボーナス）。
- 寝坊するとひよこは死んでお墓に入り、たまごからやり直しです。二度寝チェックを押せないと連続記録が0に戻ります。
- 「TODO・日課」タブでは、曜日やN日ごとの日課と、期限つきのTODOを管理します。こちらは植物が育ちます。日課をサボると−5XP、期限切れのTODOは1日ごとに−3XPで、植物がしおれます。
- 記録は端末に保存し、スプレッドシート連携をつなぐとスマホとPCで同じになります（準備は `gas/README.md`）。
- Obsidian のタスクは Mac のスクリプトでスプレッドシートに送ります（`mac/README.md`）。
