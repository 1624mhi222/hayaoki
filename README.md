# 早起き

授業の日に早起きするための、自分専用のチェックイン画面です。GitHub Pages で公開しています。

- 授業の日の朝、目標の時間までに「起きた！」、15分後に「まだ起きてる！」、授業に着いたら「授業に出た！」を押します。3つそろうと大成功です。
- 成功すると経験値が入り、ひよこが育ちます。授業を休むとひよこは死んでお墓に入り、たまごからやり直しです。
- 「TODO・日課」タブでは、毎日（または決めた曜日）の日課と、期限つきのTODOを管理します。こちらはひよことは別に、植物が育ちます。日課をサボると−5XP、期限切れのTODOは1日ごとに−3XPで、植物がしおれます。
- 記録はその端末の中だけに保存します。
