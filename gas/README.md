# スプレッドシート側の準備

1. Google スプレッドシートを新しく作る（名前は「早起き」など）。
2. 「拡張機能 → Apps Script」を開き、`Code.gs` の中身をそのまま貼って保存。
3. 左の歯車「プロジェクトの設定」→ いちばん下「スクリプト プロパティ」で、プロパティ `KEY`、値に好きな合言葉を入れて保存。
4. 右上「デプロイ → 新しいデプロイ」→ 種類「ウェブアプリ」、実行ユーザー「自分」、アクセスできるユーザー「全員」でデプロイ。許可の画面が出たら自分のアカウントで許可。
5. 出てきた URL（`…/exec` で終わる）と合言葉を、アプリの「設定 → スプレッドシート連携」に入れて「つなぐ」。スマホとPCの両方で。

## コードを新しくしたとき（例: 勉強の記録を同期するようにしたとき）

1. Apps Script を開き、`Code.gs` の中身を新しいものに貼りかえて保存。
2. 「デプロイ → デプロイを管理」→ 鉛筆マーク → バージョン「新バージョン」→「デプロイ」。URL と合言葉はそのままでOK。
